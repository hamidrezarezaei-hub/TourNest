۱. مقدمه

۱.۱ هدف سند

این سند داستان‌های کاربر (User Stories) پروژهٔ TourNest را تعریف می‌کند.

۱.۲ قالب User Story

هر User Story به این شکل نوشته می‌شود:

«به‌عنوان [نقش]، می‌خواهم [کاری] تا [ارزش].»

۱.۳ معیارهای INVEST

- Independent — مستقل
- Negotiable — قابل مذاکره
- Valuable — ارزشمند
- Estimable — قابل تخمین
- Small — کوچک
- Testable — قابل تست

۱.۴ اولویت‌بندی MoSCoW

- Must: بدون این، پروژه بی‌معنی است
- Should: مهم، اما اگر وقت نشد بعداً
- Could: خوب است داشته باشیم
- Won't: در این نسخه نداریم
